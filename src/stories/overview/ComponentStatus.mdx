# Component Status

How ready each component is. The work left on each one is listed in
`TODO.md` at the repo root.

## Status key

| Status | Meaning |
| --- | --- |
| **Planned** | An idea or an empty folder. No working code yet. |
| **In progress** | Code exists, but it's a stub or its props and behavior aren't settled. It may not have a story or tests yet. |
| **Stable** | Has a story and tests, and its props are settled. It can still have known bugs, which are listed in `TODO.md`. |

When a component changes status, update its row here. Subcomponents are
listed in brackets after their parent.
